웹 본문 추출 개인정보처리방침

최종 업데이트: 2026-10-12

1. 개요

‘웹 본문 추출’은 사용자가 현재 보고 있는 웹페이지의 본문 또는 사용자가 직접 선택한 영역을 Markdown으로 변환해 복사하거나 로컬 파일로 저장할 수 있게 하는 Chrome 확장 프로그램입니다.

2. 처리하는 정보

확장 프로그램은 사용자가 확장 아이콘을 클릭하거나 영역 선택 기능을 실행한 경우에만 다음 정보를 일시적으로 처리할 수 있습니다.

  • 현재 활성 탭의 웹페이지 내용
  • 현재 활성 탭의 URL
  • 페이지 제목, 사이트명, 작성자, 게시일 등 페이지 안에 포함된 메타데이터

확장 프로그램은 방문 기록 전체를 수집하지 않으며, 사용자가 기능을 실행하지 않은 다른 탭을 지속적으로 감시하지 않습니다.

3. 정보의 사용 목적

  • 현재 웹페이지의 핵심 본문 또는 사용자가 지정한 영역을 추출
  • 추출 결과를 Markdown으로 변환
  • 사용자가 결과를 클립보드에 복사하거나 로컬 .md 파일로 저장할 수 있도록 제공

4. 외부 전송 및 공유

추출한 웹페이지 내용과 URL은 개발자 서버나 제3자에게 전송되지 않습니다. 광고, 사용자 추적, 분석, 프로파일링, 데이터 판매 기능을 사용하지 않습니다.

5. 저장 및 보관

확장 프로그램 자체는 추출 결과를 개발자 서버에 저장하지 않습니다. 사용자가 ‘저장’을 선택한 경우 결과 파일은 사용자의 장치에 저장되며, 보관과 삭제는 사용자가 직접 관리합니다.

6. 권한

  • activeTab: 사용자가 직접 실행한 현재 탭의 내용과 URL을 일시적으로 읽기 위해 사용합니다.
  • scripting: 현재 탭에서 본문 추출 및 영역 선택을 수행하는 확장 프로그램 내 스크립트를 실행하기 위해 사용합니다.

7. 민감정보

이 확장 프로그램은 공개 웹자료 정리를 목적으로 설계되었습니다. 환자정보, 건강정보, 금융정보, 인증정보, 개인 메일, 사내 기밀 등 민감정보가 포함된 페이지에서는 사용하지 않는 것을 권장합니다.

8. Chrome Web Store Limited Use

이 확장 프로그램이 처리하는 웹페이지 정보는 사용자가 요청한 본문 추출 기능을 제공하기 위해서만 사용됩니다. 해당 정보를 광고, 재타겟팅, 신용평가, 판매, 제3자 마케팅 또는 기타 무관한 목적으로 사용하거나 이전하지 않습니다. 개발자는 사용자의 추출 내용을 열람하지 않습니다.

9. 문의

개인정보 관련 문의는 Chrome Web Store의 개발자 연락처를 통해 접수해 주세요.
